# Bibliotecas e fontes da apresentação

Cópias locais, sem build e sem CDN, para a sessão de venda funcionar sem internet. Versões fixadas; para atualizar, troque o arquivo e registre aqui.

| arquivo | biblioteca | versão | licença |
|---|---|---|---|
| `gsap.min.js` | GSAP | 3.15.0 | GSAP Standard License, gratuita inclusive para uso comercial desde a 3.13 |
| `SplitText.min.js` | GSAP SplitText | 3.15.0 | idem |
| `three/three.module.js`, `three/three.core.js` | three.js | 0.186.0 | MIT (`three/LICENSE`) |
| `three/jsm/` (postprocessing, shaders, environments, geometries, math, utils, lights) | three.js addons | 0.186.0 | MIT |

| arquivo | fonte | licença |
|---|---|---|
| `../fontes/inter-var-*.woff2`, `../fontes/inter-tight-var-*.woff2` | Inter e Inter Tight (Rasmus Andersson), variáveis | SIL Open Font License 1.1 (`../fontes/LICENCA_inter.txt`) |
| `../fontes/cormorant-garamond-*.woff2` | Cormorant Garamond (Christian Thalmann), via @fontsource | SIL Open Font License 1.1 (`../fontes/LICENCA_cormorant.txt`) |
| `../fontes/source-sans-3-*.woff2` | Source Sans 3 (Adobe), via @fontsource | SIL Open Font License 1.1 (`../fontes/LICENCA_source_sans.txt`) |

Fontes: <https://gsap.com/standard-license> · <https://github.com/mrdoob/three.js> · <https://fontsource.org>

A marca vetorial de `../midia/marca/` é gerada por `estudo/scripts/gerar_marca.py`; o instrumento 3D é desenhado por shaders próprios. Não há imagem de terceiros.
